# 🛍️ Exercício de Fixação - Sistema de Pedidos (Order System)

Projeto desenvolvido durante o aprendizado de Java para praticar relacionamentos e boa estruturação de código.

## 🛠️ Conceitos Aplicados:
* **Composição de Objetos:** Entidades conectadas (`Order` -> `Client`, `Order` -> `OrderItem` -> `Product`)
* **Enumerações:** Controle de estados do pedido com `OrderStatus`
* **StringBuilder:** Concatenação eficiente e formatação profissional de saída com o método `toString()`
* **Manipulação de Datas:** Formatação de datas com `SimpleDateFormat`
